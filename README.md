## ✨ Features / Özellikler

| Mode | Description |
|---|---|
| 🌟 **Option 1 — Pixel Art** | Convert photos into classic pixel art. / Klasik pixel art oluşturun. |
| 🧱 **Option 2 — Block Converter** | Generate mosaics using built-in Pixel Worlds Blocks and Backgrounds. / Hazır dokularla mozaik oluşturun. |
| 🛠️ **Option 3 — Photo Designer** | Edit mosaics with drawing, erasing, cloning and layer tools. / Görsellerinizi düzenleyin. |
| 🔍 **Option 4 — Project Inspector** | Load JSON projects, inspect blocks and view quantities. / JSON projelerini inceleyin. |

## 🧱 Block Converter — Option 2

- **Built-in assets:** Blocks and Backgrounds are ready to use.
- **Custom palette:** Remove or restore individual textures.
- **Conversion modes:** Blocks + Backgrounds, Blocks only, or Backgrounds only.
- **Block Quantity Terminal:** Specify exactly how many of each block to use.
- **Multiple results:** Generate different layouts from the same photo.
- **Grid toggle:** Show or hide grid lines.
- **Export:** Download PNG or editable JSON.

**Default world:** 80 × 57 blocks · 2560 × 1920 px.

**Terminal example:**

```text
Blocks/grey_brick = 150
Backgrounds/blue_glass_tile = 40
Blocks/black_block = 12
```

Specified quantities remain fixed. Remaining cells are filled automatically.

## 🛠️ Photo Designer — Option 3

| Tool | Function |
|---|---|
| ✋ Move | Pan around the canvas. |
| 🧹 Eraser | Remove placed blocks. |
| 💧 Picker | Select a block directly from the design. |
| ▣ Clone | Copy and reposition selected areas. |
| ↩ Undo | Revert the previous action. |
| 📚 Stack Blocks | Enable multiple layers in one cell. |

**Desktop:** Mouse controls, zoom, fullscreen workspace and collapsible panels.

**Mobile:** Touch drawing, pinch-to-zoom, responsive fullscreen mode and collapsible Tools/Assets panels.

Tool names appear when hovering over their icons.

## 🔍 Project Inspector — Option 4

Upload a saved `.json` project to:

- View the complete mosaic.
- Click any cell to identify its block.
- See block names, textures and quantities.
- Inspect previously saved designs.

## 📁 Installation / Kurulum

The app runs directly in your browser, without a backend.

Keep these folders together:

```text
Pixel-Art-converter/
├── index.html
├── Blocks/
├── Backgrounds/
├── Props/
└── Orbs/
```

**Important:** Extract the complete ZIP before opening `index.html`. Do not move the HTML file away from the asset folders.

**GitHub Pages:** Upload the project files to your repository and enable `Settings → Pages → Deploy from a branch → main / (root)`.
